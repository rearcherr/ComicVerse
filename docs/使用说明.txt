ComicVerse — 二次元漫画 & 轻小说阅读器（免安装版）
====================================================

【运行方式】
直接双击 ComicVerse.exe 即可，无需安装、无需 .NET 运行时。
（Windows 10/11 64 位）

【快速上手】
1. 把漫画/小说文件或文件夹直接拖进窗口，或点「添加文件 / 添加文件夹」
2. 支持的格式：CBZ/ZIP、CBR/RAR、CBT/TAR、CB7/7Z、PDF、TXT、EPUB、图片文件夹
3. 点击书架上的封面即可阅读，进度自动保存，下次打开自动续读

【阅读快捷键】
  ← / →           上一页 / 下一页（日漫模式下反向）
  PageUp/PageDown  上/下页
  Home / End       首页 / 末页
  ↑ / ↓            条漫与小说滚动
  + / -            缩放（漫画，20%–300%）
  Ctrl+滚轮         条漫模式下缩放
  F                全屏
  B                添加书签
  M / Esc          隐藏/显示工具栏

【数据位置】
书库数据库、封面缓存与日志保存在：
  %LOCALAPPDATA%\ComicVerse\
删除该目录即可完全重置（不会影响你的源文件）。
首次打开 PDF 时，程序会自动把 PDF 渲染组件释放到该目录，属正常现象。

【按书记忆】
每本漫画会记住你上次选择的阅读方式（翻页/条漫/双页）和缩放比例，
下次打开同一本书时自动恢复。

【说明与提示】
- 首次启动会比平时慢几秒，因为程序需要把内置组件自解压到临时目录，属正常现象
- 若 Windows SmartScreen 提示「已保护你的电脑」：这是未签名程序的通用提示，
  点「更多信息 → 仍要运行」即可；如需彻底消除，可购买代码签名证书后重新打包
- 若杀毒软件误报，可将 ComicVerse.exe 加入信任区（本程序不开源时建议自行审计源码）

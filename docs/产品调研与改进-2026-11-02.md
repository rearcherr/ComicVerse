# ComicVerse 产品调研与改进建议

调研日期：2026-11-02。调研代码基线：`a5a8857`（`v1.1.0`）；本轮改进已完成本地构建、核心测试、发布版冒烟及桌面交互检查。验证证据与范围见[质量检查与改进记录](质量检查与改进-2026-11-02.md)；提交发布及 CI 状态由交付流程另行记录。

本次核对了官方功能文档及本地源码，没有安装或实测竞品。下文用“调研事实”表示官方明确介绍的能力，用“代码核对”表示在 ComicVerse 当前源码中找到的行为，用“建议／推断”表示尚需设计和验证的改进判断。竞品文档会更新；涉及具体版本时仍需核实，不能把开发版功能视为稳定版承诺。

## 已有能力：避免重复建设

依据 `README.md`、`MainWindow.xaml/.cs`、`ReaderWindow.xaml/.cs`、`LibraryService.cs`、`SettingsWindow.xaml/.cs`：

- Windows 本地漫画和小说书架；文件／文件夹拖入、混合目录识别、指纹去重。
- 漫画翻页／条漫／双页、日漫 RTL、超长 PDF 切片、按需解码和 LRU 缓存。
- 阅读模式、缩放及进度按书保存；小说 TXT 编码识别、EPUB、目录、翻页／滚动和自动滚动。
- 书架网格／列表、最近阅读排序、漫画／小说筛选、书名和路径搜索。
- 右键继续阅读、从头开始、重置进度、打开目录、移出书架；已导入书籍缺失源文件时显示标记。
- 书签、深浅主题、手动备份进度数据库、免安装 Windows EXE 与 GitHub Release。

已存在的“导入后立即刷新”不等于“外部目录新增文件后自动扫描”；右键“继续阅读”也不等于首页一键打开最近一本书。

## 建议优先级

以下是结合本项目定位的判断，不是竞品实测结论。当前重点仍是 Windows 本地阅读；不建议本轮扩展跨平台、云同步、在线内容源或复杂 AI 功能。

| 优先级 | 建议 | 用户价值及规模 | 实施边界与验收要点 |
| --- | --- | --- | --- |
| P0 | 先修复审计确认的正确性问题 | 进度和书签可信，优先于新增功能 | 先复现再修复；对阅读器打开、切模式、关闭、重置及迁移添加有针对性的回归验证。 |
| P1：本轮已采纳 | 区分空书库、搜索无结果、筛选无结果；Ctrl+F 聚焦搜索，搜索框内 Esc 清空搜索 | 当前小改，减少错误引导 | 发布版冒烟通过；桌面真实输入无匹配查询显示 0/12，Esc 清空后恢复 12/12。三类空状态及组合筛选已纳入冒烟。 |
| P1：本轮已采纳 | 未读／在读／读完筛选 | 书多后更快找到该读什么，改动可控 | 状态筛选冒烟通过；已保存阅读记录但仍为 0% 的书归入在读；打开阅读窗口时重置归入未读的回归通过。真实鼠标选择读完显示 3/12。 |
| P2：本轮已采纳 | 首页一键继续最近未读完的书 | 在已有右键继续的基础上，减少查找最近一本书的操作 | 按最近阅读时间选择候选，不依赖当前筛选；排除读完和源文件不存在的记录，无候选时禁用。继续阅读候选相关冒烟断言通过。 |
| P2：下一轮 | 缩略图侧栏／页号跳转，再考虑卷间衔接 | 比单纯拖进度条更容易定位长漫画 | 缩略图按需生成并限制缓存，不能解码全书高清页；下一卷须有明确集合和自然排序，避免跳到无关书籍。 |
| P2：下一轮 | TXT／EPUB 正文搜索 | 当前只有书架标题／路径搜索，正文查找是明显缺口 | 先做跨章结果摘要和定位；后台检索支持取消；验证中文编码、排版变化、结果跳转和原进度保存。 |
| P3：较大规划 | 受管理目录重新扫描／自动更新、失联文件重新定位 | 减少手工导入和移动文件后的修复成本 | 先定义受管理目录和手动扫描，再加监控防抖；新增、覆盖与移动分开处理，重新定位保留原书 ID、书签和进度。 |

### 本轮选择理由

本轮已选择“正确性修复 + 书架找书效率”：阅读状态筛选、准确的空状态、基本搜索快捷键，以及顶部一键继续阅读均已在工作区实现。一键继续阅读也纳入本轮，是因为它可以利用已有阅读时间与进度，不需要新增书库结构。这些选择改善已有流程，不需要引入新的阅读引擎。缩略图、全文搜索和目录监控仍留待独立迭代，避免和可靠性修复一起扩大回归范围。

### 本轮代码核对结果（不是运行验收）

- `MainWindow.RefreshBooks()` 将书籍分为：未读为无最近阅读时间且进度小于 1；在读为有最近阅读时间且进度小于 1；读完为进度大于等于 1。状态筛选与类型、书名／路径搜索组合使用，未新增手工“标记读完”或伪造页码行为。
- 书架分别显示“书架还是空的”“未找到匹配的书籍”“当前筛选下没有书籍”；无匹配且书库非空时提供“清除搜索与筛选”。
- Ctrl+F 聚焦并全选书架搜索内容；Esc 仅在书架搜索框有焦点且内容非空时清空文本，不替代阅读器自身的 Esc 行为，也不清除类型／阅读状态筛选。
- 顶部继续阅读从全部书籍中按最近阅读时间选择未读完候选，跳过源文件不存在的记录；它不受当前类型、阅读状态或搜索条件影响。无候选时按钮禁用，选中候选时显示书名。
- 重置顺序已改为先关闭该书阅读窗口，再重置数据库；数据库将阅读位置清零并清除最近阅读时间，保留模式、缩放和书签。
- 已审读 README 和使用说明的新增书架描述，与上述代码一致。README 的自定义缩放范围已改为 20%–300%，与滑块和缩放钳制范围一致。

以上列出代码表达的行为；本轮主流程随后完成了 App／测试项目 Release 构建（0 警告、0 错误）、30 项核心测试和发布版 EXE 完整冒烟（exit=0）。新增状态、继续阅读候选、空状态、阅读窗口打开时重置、缩放记忆相关断言均通过。真实桌面输入与鼠标筛选结果正确，980 DIP 最小窗口截图可读。详细证据及限制见[质量检查与改进记录](质量检查与改进-2026-11-02.md)，本报告不将生成样例通过扩大解释为任意文件均正确。

## 已验证结果与后续专项

1. **已验证：重置进度。** 先关窗再重置的回归通过，打开真实阅读窗口时执行重置后，旧位置不会被关闭保存写回，模式与缩放保留；书签保留与数据库操作边界见质量记录。
2. **已验证：阅读状态与书架新流程。** 状态筛选、继续阅读候选、三类空状态与组合查询已通过发布版冒烟。真实输入无匹配后 Esc 恢复，以及鼠标选择读完均检查通过；一页／一屏小说读完语义也已有回归覆盖。
3. **已验证：文档与界面一致性。** README 自定义缩放范围已修正为 20%–300%，与控件一致；缩放同步及按书恢复通过冒烟。新增书架描述与代码一致，最小窗口截图可读。这些本地结果不等于远端发布已经完成。
4. **后续专项：网络盘和大库响应。** 源路径同步检查在网络盘、成千上万本书或大量失联路径下的响应时间仍未实测，不能声称已解决这类卡顿。
5. **后续专项：历史指纹兼容。** 历史指纹算法变化后，大文件移动重新识别的升级兼容性尚未覆盖，需要历史书库副本专项验证。本轮未扩大修改匹配规则。
6. **后续专项：真实复杂文件组合。** RAR／7Z 大包、复杂或损坏 EPUB、缺失系统图片编解码器等未穷尽；后续功能仍按前述优先级独立推进。

## 资料使用边界

本报告只引用官方产品页面、官方文档及项目维护者仓库，未采用第三方下载站、内容获取站或社区传言作为功能依据。不同产品的能力体现了可借鉴方向，并不自动意味着 ComicVerse 应全部实现。最终优先级应由已复现缺陷、现有用户操作习惯和回归成本共同决定。

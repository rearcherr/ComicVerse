# ComicVerse 团队检查与改进记录

日期：2026-11-02。基线：`a5a8857`（v1.1.0）。本轮交付：v1.2.0，Windows 桌面版。

## 分工与方法

Leader 负责范围取舍、书架实现、交叉复核、完整构建和发布验证；三个子 agent 分别负责官方竞品调研、核心数据与解析审查、阅读器交互审查。共享目录按文件分工，提交与发布集中由 Leader 完成。

竞品仅查阅官方文档，没有安装竞品实测。详见[产品调研与改进](产品调研与改进-2026-11-02.md)。本轮选择改善找书效率和现有阅读可靠性；缩略图导航、正文搜索、卷间衔接和目录监控分别留作独立迭代。

## 本轮新增能力

- 未读／在读／读完筛选，可以和漫画／小说及书名／路径搜索组合。
- 已打开但仍为 0% 的书算在读；重置后算未读，保留模式、缩放和书签。
- 顶部继续阅读打开最近未读完且源路径仍存在的书，与当前筛选独立；源文件重新出现时清除旧失联标记。
- 分开提示空库、搜索无结果和筛选无结果，提供清除搜索与筛选；Ctrl+F 聚焦搜索，搜索框内 Esc 清空。

## 已确认并修复的问题

| 问题 | 触发及原行为 | 修复与验证 |
| --- | --- | --- |
| 导入取消回滚阅读数据 | 异步批次导入在书库共用连接上持有事务；同时保存进度、设置和书签，取消导入也会把它们回滚 | 每本解析完成后短时原子保存，保留已导入书籍。隔离编译旧 ImportService 的探针确认：新页码 59 回退到 9、主题变 NULL、书签变 0；新实现回归保留这些数据 |
| 刷新元数据覆盖新进度 | 导入取得旧 Book 快照后，用户保存了新位置，随后全字段 Upsert 将旧进度写回 | 新增只更新元数据的 SQL，不写 progress／last_read；独立连接检查新进度与元数据均保留 |
| 同目录单图串页 | 分别打开 A.png 与 B.png，两者以父目录作 SourcePath，共用页 0 缓存 | 单张图用完整文件路径作源标识；不同尺寸 A/B 和整个图片文件夹共用缓存的回归通过 |
| 自然排序违反比较器契约 | 不同文字块且块数相同时，正反比较都返回正数，页序不稳定 | 返回真实文字比较值；补文字前缀、目录名、反对称与传递性检查 |
| 重置被关闭保存覆盖 | 打开阅读器时先清零再关窗，Closing 把旧位置写回 | 先关窗再重置，并清空最近阅读时间；真实阅读窗口打开时重置通过，模式与缩放保留 |
| 小说分页 API 偏一页 | 内部从 0 开始的索引直接传入 WPF 从 1 开始的 GoToPage | 在 API 边界统一加 1；实际显示页号与内部索引分别断言 |
| 小说异步分页尚未完成就换章 | Loaded 时把暂时页数 1 缓存为最终值，下一页直接接章，恢复位置也被过早钳制 | 等待 PaginationCompleted 再恢复和定位；翻页读取真实页数；文档／模式变化或关窗时取消旧回调 |
| 切条漫丢失或偏离当前页 | 首次切换用默认比例 0 回到书首，再次切换用页数比例代替实际高度 | 从翻页／双页切入按页顶定位，仅重开原条漫会话恢复比例；不等高页面首次和再次切换均断言准确页码 |
| 小说章内滚动不自动保存 | 普通滚轮或拖动滚动条没有 ScrollChanged 同步，正常关闭能保存但自动保存不发生 | 真实滚动更新进度并安排防抖保存；布局恢复期间保护原位置。先等旧保存计时器结束，再只滚真实视口验证重新保存，避免假阳性 |
| 本书排版污染全局默认 | 先改字号再切主题，将局部设置整份写为全局 | 主题仅改当前窗口颜色；改字号再切两次主题，检查本书保留且全局未变 |
| 一页／一屏短篇永远无法读完 | 单页章节内进度固定为 0，最终章也达不到 100% | 真实分页完成或滚动布局稳定且完整显示一屏时算该章完成，滚动坐标仍保存 0；两种小说模式均验证 |
| UTF-32LE BOM 被当成 UTF-16LE | 长 BOM 的 FF FE 前缀先匹配短 BOM | 先检测 UTF-32LE/BE，再检测 UTF-16；中文与 emoji 往返验证 |
| 深色主题下拉选中文字黑色 | 内层 ToggleButton 没有继承 ComboBox 前景色 | 显式绑定主题文字色；截图及真实下拉菜单目视检查 |
| 无人值守启动错误弹窗挂住 | 自检启动异常后等待 MessageBox 关闭 | --smoke 启动异常写 stderr 并以非零码退出 |

## 完成的验证

- App 与测试项目 Release 构建：0 警告、0 错误，启用 warnaserror。
- 核心测试：30 项通过、0 项失败。覆盖 ZIP/TAR/文件夹/PDF、TXT/EPUB、编码、远跳、缓存、书库并发、旧库迁移和本轮数据回归。新增四项独立测试，并加强自然排序与 BOM 检测测试。
- 自包含单文件 `publish/ComicVerse.exe` 执行完整 `--smoke`：exit=0。使用独立书库，不修改用户的真实书库和进度。

- 漫画翻页／条漫／双页、RTL、远跳、缩放同步与按书记忆、鼠标拖拽及横向平移、PDF、小说滚动跨章、主题、恢复进度、导入立即刷新均通过。

- 桌面交互检查：真实输入不匹配查询后显示 0/12 和正确提示；Esc 清空后恢复 12/12；鼠标下拉选择读完后显示 3/12；深色菜单可读。检查了 980 DIP 最小窗口及 1280 DIP 截图。
- 冒烟证据保存在本地 `artifacts/published-smoke-3c3dd60d/`：`summary.txt`、截图和独立数据。该目录不提交 Git；CI 会重新生成并上传自己的冒烟证据。

## 仍需专项验证的范围

- 历史版本指纹算法改变后，大文件移动重新识别的升级兼容性：本轮没有擅自改变匹配规则，需用历史书库副本专项验证。
- 网络盘及成千上万本书时，源路径同步检查的响应时间；没有实测就不能声称解决了这类卡顿。

- 缩略图／页号导航、TXT／EPUB 正文搜索、明确集合中的下一卷、受管理目录扫描和失联文件重新定位，按调研报告单独推进。

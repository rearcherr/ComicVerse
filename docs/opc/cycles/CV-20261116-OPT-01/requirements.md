## 用户任务与范围

目标用户是假设中的 Windows 本地漫画读者，已知阅读器目标页号并希望回看。一句话价值：直接输入页号到达阅读位置，并保持原有阅读与恢复规则。迁移收益、使用频率及满意度均未验证。

主流程：打开漫画并可定位 → 点击底栏页号或 Ctrl+G → 浮层显示“页码（1–N）”，预填当前实际页并全选 → 输入目标 → Enter 或浮层“跳转”按钮提交 → 关闭浮层并返回阅读焦点 → 现有导航链加载／定位 → 按实际结果更新页号与保存。

- 适用单页、双页、条漫；LTR／RTL 共用自然阅读序号，RTL 只改变现有视觉排列及翻页方向。小说不展示此入口，Ctrl+G 不触发漫画定位。
- 页码为 1 基，范围 1–N；提交前去掉首尾空白，只接受 ASCII 十进制数字，允许前导零；空白、符号、小数、非数字、数值溢出、0、N+1 拒绝，不自动夹取到边界。错误提示“请输入 1–N 的整数页码”，浮层保持可修改。
- 浮层 Esc 仅取消草稿并返回阅读焦点，不关闭阅读器或退出全屏；点击浮层外取消，不提交。重复 Ctrl+G 聚焦同一浮层，不重复创建。编辑时方向键／Home/End 等交给文本框，B/F/M 不触发阅读快捷键。
- 浮层打开时停止工具栏自动隐藏，确保可输入；切模式或关闭阅读器丢弃未提交草稿。已提交的导航由既有状态机管理，不能被“取消草稿”撤销或改写。
- 初始化／页数未知、N=0、打开失败时入口不可提交；条漫布局尚未就绪时不可发起新提交，恢复可定位后启用。分页／双页已经就绪后的慢加载允许新有效提交取代旧目标。
- 不新增进度字段、书签精度或数据库迁移，不生成全书缩略图、不扫描全书高清图、不改小说或格式解析器。浮层仅保存会话草稿，不持久化输入。

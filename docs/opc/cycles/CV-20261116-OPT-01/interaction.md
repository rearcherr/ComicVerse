# 漫画精确页码跳转交互

leader，2026-11-16。依据当前底栏源码和 IDEA-003，作为本轮模拟走查与实现规格；尚无真实用户可用性反馈。

- 入口：保留底栏 `PageInfoText` 的成功页码文字，漫画可点击该页码（`PageJumpButton`），提示“跳到指定页 (Ctrl+G)”。小说页码仍只显示文本；未完成初始化时不允许提交。
- Ctrl+G 在漫画阅读器打开居中的轻量输入浮层，即使工具栏隐藏也可用。浮层覆盖阅读区和工具栏，阻止底层点击；不新建原生对话框。重复打开只聚焦并选中输入。
- 浮层 `PageJumpPanel` 包含标题“跳到指定页”、输入 `PageJumpInput`、范围 `PageJumpRangeText`、校验消息 `PageJumpErrorText`、`PageJumpConfirmButton` 和 `PageJumpCancelButton`。输入预填最后成功显示页（双页为组首、条漫为实际视口页），未有成功画面时使用合法初始页。数字从 1 开始，范围与底栏总页数一致，含 PDF 切片后的页数。
- 输入去除首尾空白后，仅接受 ASCII 十进制整数；前导零允许。空白、负数、加号、小数、混合字符、全角数字、溢出及不在 1..N 范围的值显示内联错误，保留内容并聚焦输入，不导航、不钳制、不更改或取消已有请求。
- 点击“跳转”或 Enter 提交一次；有效输入关闭浮层并调用当前模式既有导航入口。分页显示目标页；双页显示包含目标页的完整规范分组，RTL 只改变左右顺序；条漫定位目标页顶部，受末尾滚动边界限制时以实际可见位置为准。
- Escape、“取消”或点击浮层背景只关闭浮层，保留阅读窗口和成功位置；失焦不提交。关闭后焦点回到阅读区域。浮层打开时，编辑方向/Home/End/空格/删除等键交给控件，不触发翻页、书签、全屏或工具栏快捷键；Tab 在浮层内循环，提供可访问名称。编辑期间停止工具栏自动隐藏；模式变化清除草稿。
- 有效提交后的加载、失败、重试、快速覆盖和切模式行为沿用既有请求/成功事实模型。新入口不直接更新成功页码或保存数据库。加载失败仍保留上一成功画面，可再打开输入指定其它页。
- 默认及最小窗口宽度检查浮层与底栏布局；深浅主题采用现有资源；不常驻新增宽输入框，不增加图像缓存。

验收以独立 QA 的真实控件事件、图像/页码/数据库观察和离屏截图为准；本文的模拟设计不等于运行通过。

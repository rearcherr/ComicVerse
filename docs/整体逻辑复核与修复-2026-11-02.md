# ComicVerse 整体逻辑复核与修复

## 本轮发现与处理

| 逻辑路径 | 证据与问题 | 修复 |
| --- | --- | --- |
| TXT首章解析 | 原Core DLL实测：同样的两章文本，UTF-8/16/32 BOM会让首标题漏检；无BOM正常 | 仅消除文本开头的BOM，保留正文内U+FEFF；真实字节解码到章节解析回归覆盖6种编码 |
| 设置落盘失败及同值重试 | 临时SQLite触发器实测：首次写入失败后cache已更新，重试相同值直接早退，重启仍旧值 | 区分会话值与待持久化状态，串行写入；失败保留dirty，同值可重试；按书保存返回成功与否，Reader成功后才清未保存状态 |
| 导入路径展开 | 源码确认空闲门闩后的目录展开仍在调用线程，扫描时不检查取消，错误可能被吞 | 路径及目录扫描先在后台完成，枚举检查取消，取消显式抛出；扫描错误纳入Failed，重叠输入去重；逐书原子保存和串行导入语义保留 |
| 横竖混排双页 | 独立QA基线实测：竖竖横竖竖反向会落到竖横错误组合；竖横相邻时也会被合并并跳过横页 | 按横页边界和竖页run奇偶确定稳定分组；横页单独显示，Next/Prev沿同一分组来回；逐次队列保留边界操作次序，最后一组不重复末页 |
| 双页进度和快速切模式 | 源码复核发现末尾完整双页继续Next会重复末页；异步导航可能晚于模式切换 | 以可见末页计算完成比例；模式、显式跳页和关闭使旧导航作废；取尺寸在后台，未完成导航不当作已稳定画面 |
| 长条漫同页自动保存 | 独立QA基线实测：单张400×12000页滚到0.65，等2.6秒仍开窗时DB为0；仅换页才通知 | 页内真实纵向位置变化独立通知、防抖保存；页号不变也保存最新fraction；隐藏/卸载停止滚动定时器 |
| 条漫初始化与恢复 | 源码审查发现旧异步恢复只看当前mode，返回条漫后可能覆盖较新目标；未ready的-1/0也可能写回历史进度 | 共用初始化Task，按entry版本仅最新恢复生效；未完成恢复不读取默认快照、不保存，切模式保留已载入位置；内容未初始化就关闭也不写0覆盖 |
| 小说翻页／滚动切换 | 旧临时宿主观察到后页切滚动回0、滚动70%后切分页仍为旧页；最终证据须由真实App复验 | 用户切换前读取当前实际比例，目标模式布局后恢复；初始化赋值不当作用户切换。当前为章节比例映射，不宣称精确文字锚点 |
| 小说末页定位意图 | 源码确认End或上一章末页请求可在中断后残留，再进同章误跳末页 | 加载入口消费请求，绑定本次文档的局部意图；旧文档取消后不影响后续进入章节 |
| 书签删除及空白点击 | 旧临时宿主观察到删除按钮的PreviewMouseUp先被父列表当导航；最终证据须由真实App复验 | 仅激活实际命中行的正文，排除行内按钮及子元素，空白不导航；不扩大原有页／章节级书签能力 |
| 自动滚动手动停止 | 旧临时宿主观察到没先滚轮时点击正文仍继续；原处理仅重置wheel目标 | 正文常驻鼠标／键盘／触摸输入处理，停止自动滚动并清旧wheel目标，仍保留正常恢复流程 |
